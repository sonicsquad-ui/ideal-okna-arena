# Инструкция по быстрому развертыванию сайта «Чемпион-Теннис» на хостинге REG.RU

## ⚠️ Причина проблемы со скриншота и что было исправлено

На приложенном скриншоте было видно:
1. Текст отображался плоским списком без стилей.
2. Векторный логотип тенниса развернулся в гигантский желтый полукруг на весь экран.

### В чем была причина:
* Статические ресурсы (CSS-стили, JS-скрипты и изображения) находились во вложенной папке `public/` (`public/css/main.css`), а страница запрашивала их по прямому адресу `/css/main.css`.
* Сервер Apache на хостинге перенаправлял запрос `/css/main.css` на `index.php`, который возвращал HTML-страницу вместо CSS-файла. Браузер отклонял некорректный MIME-тип и не применял стили оформления.
* Без CSS-правил векторный SVG-логотип отображался браузером по умолчанию на 100% ширины экрана.

### Что сделано для 100% решения:
1. **Автоматический стример ресурсов в `index.php`**: если Apache передает запрос к `/css/`, `/js/`, `/images/` в `index.php`, скрипт сам мгновенно находит файл (как в корне, так и в `public/`), отдает правильный заголовок `Content-Type: text/css` (или `image/jpeg`) и кэширует его.
2. **Встроенные критические стили (`<style>`) прямо в `<head>`**: базовые цвета, шрифты, сетка и жесткие ограничения размера логотипа (`width: 44px; height: 44px;`) теперь встроены непосредственно в HTML-код. Страница будет мгновенно выглядеть идеально даже при медленном соединении.
3. **Прямое ограничение SVG-логотипа**: тегу `<svg>` заданы жесткие HTML-атрибуты `width="26" height="26" style="max-width:26px; max-height:26px;"`, исключающие растягивание на весь экран.
4. **Обновлен `.htaccess`**: добавлены правила автоматического перенаправления запросов `/css/(.*)`, `/js/(.*)`, `/images/(.*)` в подпапку `public/`.
5. **Сформирован готовый архив `regru-php-deploy.zip`**: папки `css/`, `js/`, `images/` продублированы и в корне, и в `public/`, чтобы сайт гарантированно работал при любой структуре распаковки.

## 🛠️ Что сделать прямо сейчас на хостинге REG.RU (за 1 минуту)

### Вариант 1 (Самый быстрый через архив `regru-php-deploy.zip`):
1. Зайдите в панель управления хостингом REG.RU (**ISPmanager** или **cPanel**).
2. Откройте **«Менеджер файлов»** и перейдите в корневую директорию вашего сайта (папка `public_html/` или `data/www/champion-tennis.ru/`).
3. Загрузите файл **`regru-php-deploy.zip`** (размером 4.6 МБ) прямо в эту папку.
4. Нажмите правой кнопкой мыши по архиву &rarr; **«Извлечь»** (или «Распаковать»).
5. Обновите страницу `https://champion-tennis.ru/` в браузере (нажмите `Ctrl + F5` для очистки кэша). Сайт откроется в полном дизайнерском виде!

### Вариант 2 (Если файлы уже распакованы на сервере):
Если вы уже скопировали файлы на хостинг, достаточно:
1. Заменить файлы **`index.php`** и **`.htaccess`** в корне сайта на обновленные версии из папки `regru-php-deploy/`.
2. Скопировать папки `css`, `js`, `images` из папки `public/` прямо в корень сайта (рядом с `index.php`).

## ⏰ Настройка автоматического обновления новостей (Cron 8:00 МСК)

Чтобы новости автоматически собирались и уникализировались каждый день в 8:00 утра по Москве:
1. В панели управления REG.RU откройте **«Планировщик заданий (Cron)»**.
2. Создайте задание с расписанием: `0 8 * * *`
3. Команда выполнения:
   ```bash
   /opt/php/8.2/bin/php /var/www/uXXXXXXX/data/www/champion-tennis.ru/cron_news.php
   ```
   *(где `uXXXXXXX` — логин вашего аккаунта на REG.RU)*.

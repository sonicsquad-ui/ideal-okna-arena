# Инструкция: Автообновление новостей, матчей, рейтингов и турниров на хостинге REG.RU

Данное руководство подробно и пошагово описывает, как настроить автоматический ежедневный сбор и рерайт новостей с 5 ведущих теннисных ресурсов на вашем сайте **champion-tennis.ru**, привязав задачу к планировщику **Cron на хостинге REG.RU на 08:00 по московскому времени (МСК)**.

---

## 1. С каких источников и что собирается

Скрипт `cron_news.php` производит автоматический мониторинг и синхронизацию:

| Источник | Раздел источника | Категория на champion-tennis.ru |
| :--- | :--- | :--- |
| **Спорт-Экспресс** | `https://www.sport-express.ru/tennis/` | **ATP** (Мужской тур) / Главные события дня |
| **Sports.ru** | `https://www.sports.ru/tennis/` | **WTA** (Женский тур) / Эксклюзивы |
| **Чемпионат** | `https://www.championat.com/news/tennis/1.html` | **Большой шлем** (Grand Slam) / Превью |
| **РИА Новости Спорт** | `https://ria.ru/tennis/` | **Сборная России** / Первенства РТТ |
| **TennisBB / GoTennis** | `https://tennisbb.ru/news` | **Падел и Пиклбол** / Турниры |

### Что обновляется каждый день в 08:00 МСК:
1. **Новости тенниса**: Загружаются свежие инфоповоды, генерируются уникальные рерайт-заголовки, лиды и тексты статей, формируются правильные теги рубрик, дата публикации в формате `ДД.ММ.ГГГГ ЧЧ:ММ` и привязываются тематические обложки.
2. **Виджет «Матчи сегодня» (`matches`)**: Обновляются сегодняшние встречи лидеров мирового тура (Медведев, Рублев, Андреева, Синнер, Алькарас), счет по сетам и геймам, текущие статусы (*LIVE, 3-й сет, Завершен, Скоро*).
3. **Официальные рейтинги ATP и WTA (`rankings`, `players`)**: Синхронизируются очки теннисистов и теннисисток в мировом табеле о рангах.
4. **Турнирный календарь (`tournaments`)**: Актуализируются текущие раунды (квалификация, 1/4, полуфиналы, финалы).
5. **Логирование**: Результаты работы сохраняются в базу данных (`global_blocks`) и выводятся в отчете.

## 2. Способ 1: Настройка в панели ISPmanager (REG.RU)

Если на вашем тарифе REG.RU установлена панель **ISPmanager**:

1. Войдите в панель управления ISPmanager через личный кабинет REG.RU.
2. В левом вертикальном меню перейдите в раздел **«Инструменты»** → **«Планировщик (Cron)»** (или просто пункт **«Планировщик»**).
3. В верхней панели нажмите кнопку **«+ Создать»** (или «Добавить задание»).
4. Заполните поля формы:
   - **Описание / Комментарий:**  
     `Champion-Tennis: Автосбор новостей и обновление матчей 8:00 МСК`
   - **Команда:**  
     Вставьте одну из следующих команд:

     **Вариант А (рекомендуемый — запуск через CLI PHP):**
     ```bash
     /opt/php/8.2/bin/php /var/www/uXXXXXXX/data/www/champion-tennis.ru/cron_news.php >/dev/null 2>&1
     ```
     *(Вместо `uXXXXXXX` укажите ваш логин пользователя хостинга в REG.RU, путь к сайту можно посмотреть в разделе «Сайты» / «WWW-домены»).*

     **Вариант Б (универсальный через WGET по защищенному Webhook):**
     ```bash
     wget -q -O - "https://champion-tennis.ru/cron_news.php?token=champion2026secret" >/dev/null 2>&1
     ```
     *(Этот вариант работает абсолютно на любом сервере без необходимости знать точный внутренний путь к PHP).*

   - **Расписание (Запуск ровно в 08:00 МСК):**
     - В переключателе выберите **«Экспертный режим»** (или настройте поля):
     - **Минуты:** `0`
     - **Часы:** `8` *(если время сервера настроено по МСК Europe/Moscow)*  
       *(Примечание: если часы сервера работают по UTC, укажите `5`, так как 05:00 UTC = 08:00 MSK).*
     - **Дни месяца:** `*`
     - **Месяцы:** `*`
     - **Дни недели:** `*`
     - Итоговая cron-строка: `0 8 * * *` (или `0 5 * * *`).
5. Нажмите кнопку **«Сохранить»**.

## 3. Способ 2: Настройка в панели cPanel (REG.RU)

Если на вашем хостинге REG.RU установлена панель **cPanel**:

1. Откройте панель **cPanel**.
2. В блоке **«Расширенный»** (Advanced) кликните на иконку **«Задания Cron»** (Cron Jobs).
3. Прокрутите страницу до блока **«Добавить новое задание cron»** (Add New Cron Job).
4. В выпадающем списке «Общие параметры» выберите **«Один раз в день (0 0 * * *)»**, затем скорректируйте:
   - **Минута:** `0`
   - **Час:** `8` *(или `5` при UTC)*
   - **День:** `*`
   - **Месяц:** `*`
   - **День недели:** `*`
5. В поле **«Команда»** (Command) введите:
   ```bash
   /usr/local/bin/php /home/uXXXXXXX/public_html/cron_news.php >/dev/null 2>&1
   ```
   *или через curl:*
   ```bash
   curl -s "https://champion-tennis.ru/cron_news.php?token=champion2026secret" >/dev/null 2>&1
   ```
6. Нажмите кнопку **«Добавить задание cron»**.

## 5. Дополнительно: Подключение нейросетевого рерайта через нейросети (OpenAI / YandexGPT)

Если вы хотите, чтобы каждый текст переписывался нейросетью YandexGPT или OpenAI ChatGPT для 100% уникальности по Text.ru / Advego:

В файле `cron_news.php` функция `rewriteHeadline()` может быть дополнена вызовом API YandexGPT:

```php
function aiRewriteWithYandexGPT($rawText, $apiKey, $folderId) {
    $url = "https://llm.api.cloud.yandex.net/foundationModels/v1/completion";
    $payload = [
        "modelUri" => "gpt://{$folderId}/yandexgpt/latest",
        "completionOptions" => ["stream" => false, "temperature" => 0.6, "maxTokens" => 1200],
        "messages" => [
            ["role" => "system", "text" => "Ты спортивный теннисный журналист. Перепиши новость своими словами в профессиональном авторском стиле, сделай броский заголовок и краткий лид."],
            ["role" => "user", "text" => $rawText]
        ]
    ];

    $ch = curl_init($url);
    curl_setopt($ch, CURLOPT_HTTPHEADER, [
        "Content-Type: application/json",
        "Authorization: Api-Key " . $apiKey
    ]);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($payload));
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_TIMEOUT, 15);
    $response = curl_exec($ch);
    curl_close($ch);

    $json = json_decode($response, true);
    return $json['result']['alternatives'][0]['message']['text'] ?? $rawText;
}
```

Все необходимые хуки уже встроены в `cron_news.php`, поэтому вы можете подключить ключ в любой момент в настройках `config.php`.

# Инструкция по развертыванию сайта Профориентолога Марины Бондаревой (orientirprof.ru) на простом хостинге

Этот сайт спроектирован и подготовлен специально для **простого стандартного хостинга** (не требует VPS, SSH или сложных команд). Он работает «из коробки» на любом российском виртуальном хостинге (Beget, TimeWeb, Reg.ru, Spaceweb, Masterhost, cPanel и др.) с поддержкой PHP 7.4 / 8.0+.

---

## 2. Пошаговая инструкция по установке на хостинг (за 5 минут):

### Шаг 1. Скачайте архив сайта
Скачайте готовый архив `orientirprof-site.zip` из панели управления (кнопка **«📦 Скачать ZIP для хостинга»**) или из папки проекта.

### Шаг 2. Войдите в панель вашего хостинга
Зайдите в личный кабинет вашего провайдера (например, [Beget](https://beget.com), [TimeWeb](https://timeweb.com), [Reg.ru](https://reg.ru)):
1. Откройте раздел **«Сайты»** или **«Домены»** и убедитесь, что домен `orientirprof.ru` добавлен.
2. Откройте **«Файловый менеджер»** (или подключитесь по FTP через FileZilla).
3. Перейдите в корневую директорию сайта (обычно это папка `public_html`, `www` или `orientirprof.ru/public_html`).

### Шаг 3. Загрузите и распакуйте архив
1. Загрузите архив `orientirprof-site.zip` в корневую папку сайта.
2. Нажмите правой кнопкой мыши по архиву и выберите **«Распаковать архив»** (Extract).
3. Убедитесь, что файл `index.html`, папки `css/`, `js/`, `images/`, `data/`, `admin/`, файл `.htaccess` и файл `robots.txt` находятся непосредственно в корневой папке сайта (не внутри лишней подпапки).

### Шаг 4. Привязка домена https://orientirprof.ru/
1. Если домен уже зарегистрирован и направлен на ваш хостинг: сайт откроется сразу.
2. Если домен зарегистрирован у другого регистратора: в панели регистратора пропишите NS-серверы вашего хостинга (или укажите A-запись с IP-адресом вашего хостинга).
3. В панели хостинга включите бесплатный SSL-сертификат **Let's Encrypt** в 1 клик, чтобы сайт открывался по безопасному протоколу `https://`.

## 4. Как пользоваться панелью управления (CMS):

- Адрес входа: `https://orientirprof.ru/admin/`
- **Логин:** `admin`
- **Пароль:** `OrientirProf2026!*`

### Возможности панели управления:
1. **Редактор страниц:**
   - Выберите любую страницу из списка для редактирования.
   - Можно менять заголовок H1, текст, подзаголовок, мета-теги Title, Description, Keywords.
   - Можно создать новую страницу по кнопке «+ Создать новую страницу» (задав slug URL, текст и галочку добавления в меню).
2. **Шапка и контакты:**
   - Редактирование номеров телефонов, адреса в Орле, режима работы, пунктов навигации.
3. **Футер:**
   - Редактирование текста «О себе», ссылок на мессенджеры (WhatsApp, Telegram, VK), копирайта и текста cookies.
4. **robots.txt:**
   - Полноценный текстовый редактор файла robots.txt с мгновенным сохранением в корень сайта.
5. **Микроразметка Schema.org:**
   - Настройка названия организации, ФИО специалиста, геокоординат.
6. **Блог и статьи:**
   - Добавление, редактирование и удаление статей.
7. **Кейсы клиентов:**
   - Добавление реальных историй успеха клиентов.
8. **Журнал заявок (Лиды):**
   - Просмотр всех заявок с сайта с контактами клиентов, результатами тестов и возможностью экспорта в CSV.
9. **Смена пароля:**
   - Вы можете в любой момент сменить пароль администратора на свой собственный.
